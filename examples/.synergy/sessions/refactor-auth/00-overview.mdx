# Refactor auth middleware

<Status value="proposed" note="Awaiting design review" />

## Summary

The current auth middleware stores session tokens in a way that doesn't meet our updated compliance requirements. This session refactors the middleware into a token-handling layer that separates issuance, storage, and verification, with a clean migration path for existing sessions.

## Goals

- Replace token storage with the compliance-approved store.
- Keep the public middleware API stable — no changes for downstream services.
- Migrate existing sessions without forcing users to re-login.
- Add structured logging at every token operation.

**Out of scope:** OAuth provider changes, session timeout policy, password hashing.
