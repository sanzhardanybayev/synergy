# Make the README s-tier

<Status value="proposed" note="Awaiting approval, then implement in one pass" />

## Summary

The current `README.md` documents Synergy correctly but reads like a reference manual. The goal here is to turn it into a great first impression: a clear hook that explains why Synergy exists, a demo GIF/screenshot so the value is obvious without reading, an opinionated install path that works in one or two commands, and a complete reference that's scannable rather than narrative. We're not adding new product surface — just packaging what's already there so the README earns the install.

## Goals

- **Sells the value in 10 seconds.** A new reader understands what Synergy does and why they'd use it from the top of the file alone.
- **Visual proof.** At least one screenshot or animated GIF showing the preview rendering a session.
- **One install paragraph.** The marketplace install + `/synergy-setup` flow, with prerequisites listed inline.
- **Full reference, scannable.** All slash commands, all CLI subcommands, all spec-kit components in tables — not paragraphs.
- **Troubleshooting section.** The three failure modes we've already seen documented as FAQ entries.
- **Out of scope:** new product features, new components, new commands, new examples beyond the one we already have.
