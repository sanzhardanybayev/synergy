# Implementation Plan

A small, single-pass refactor. The work splits cleanly into three short phases, but they're sequential — no point parallelizing 30-minute chunks. See <CrossRef to="01-architecture#section-blueprint">the section blueprint</CrossRef> for the target shape.

## Phases

- <CrossRef to="phases/capture-screenshot" /> — capture the demo asset.
- <CrossRef to="phases/rewrite-readme" /> — rewrite README against the eight-section blueprint.
- <CrossRef to="phases/link-validate" /> — link-check and run the validator.

Each phase has its own folder under `phases/` with a `spec.mdx` and a short `orchestrator.md`.
